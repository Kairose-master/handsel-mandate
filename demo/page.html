02 / 에이전트 구매 실행

        
발견 → 예산 확인 → 결제 → 결과

        

        
        

        
    
          
  1. 1
    상품 발견
    product.json과 유료 엔드포인트를 읽습니다.
    2. 
          
  2. 2
    402 견적 수신
    PAYMENT-REQUIRED 헤더에서 가격·네트워크·수취 주소를 읽습니다.
    3. 
          
  3. 3
    허용 예산 확인
    건당 한도와 남은 총예산 안에 있어야 서명합니다.
    4. 
          
  4. 4
    테스트넷 결제
    EIP-3009 서명을 PAYMENT-SIGNATURE로 보내고 응답을 받습니다.
    5. 
          
  5. 5
    결과 수령
    변환된 JSON과 정산 정보를 확인합니다.
    6.

05 / 내 도구도 팔고 싶다면

    
작동하는 API를 가진 개발자 3명과 첫 판매 흐름을 함께 만듭니다.

    
    
      
  1. 엔드포인트 하나를 보냅니다. 입력·출력 예제와 호출당 가격(USDC), 수취 주소면 충분합니다. 비밀키나 고객 데이터는 받지 않습니다.
    2. 
      
  2. 결제 게이트를 붙입니다. 코드는 그대로 두고, 결제된 호출만 공유 비밀 헤더와 함께 API로 전달하는 x402 프록시를 세웁니다. 실패한 호출에는 정산이 없습니다.
    3. 
      
  3. 구매 링크를 받습니다. 위와 같은 페이지, 에이전트가 읽는 product.json, 402 → 서명 → 결과 한 줄 예제. 기존 소개 글과 문서에 붙이면 됩니다.
