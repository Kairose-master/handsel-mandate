# 402-LAB 이용 안내

최종 갱신 2026-09-25. 이 문서는 https://handsel-mandate-demo.vercel.app 에서 판매하는 API와 402-LAB MCP 서버에 적용됩니다.

## 결제
- 결제는 x402 프로토콜(exact 방식, Base 메인넷 USDC, EIP-3009 서명)로 호출 한 번마다 이뤄지며, 판매자 수취 주소 `0xe818cf591E65C93600311E789f25301138299232`로 직접 정산됩니다. 정산은 CDP facilitator가 수행하고 Basescan에서 확인할 수 있습니다.
- 가격은 402 응답의 견적이 기준이며 사전 고지 없이 바뀔 수 있습니다. 구매자 쪽 클라이언트는 결제 전에 항상 402 견적을 먼저 받습니다.
- 에스크로와 환불은 없습니다. 도구가 2xx가 아닌 응답을 내면 검증된 결제를 취소해 정산이 일어나지 않지만, 정산이 끝난 뒤의 결과 불만족은 환불 대상이 아닙니다.
- 이 서비스는 개발자 프리뷰입니다. 가용성·응답 시간·지속 제공을 보장하지 않습니다.

## 상품: 사업자등록 상태 조회 (국세청)
- 출처: 국세청 사업자등록정보 진위확인 및 상태조회 서비스(공공데이터포털, 이용허락범위 제한 없음). 결과의 정확성은 국세청 데이터에 따릅니다.
- 한 번에 최대 100건. 업스트림 한도(하루 100만 건)는 모든 구매자가 공유합니다.
- 입력한 사업자등록번호는 저장하거나 로그에 남기지 않습니다. 정산 기록(구매자 지갑 주소, 금액, 트랜잭션)은 공개 블록체인에 남습니다.

## 판매자(API 제공자)
- 판매자 프록시는 판매자의 기존 API 앞에 결제 게이트를 세우고, 결제된 호출만 공유 비밀 헤더와 함께 전달합니다. 판매자 API는 그 헤더가 없는 호출을 거부해야 합니다.
- 402-LAB은 판매자 API의 내용·품질·적법성을 보증하지 않습니다. 판매자는 자신의 데이터 이용 조건을 지킬 책임이 있습니다.
- 수수료: 프리뷰 기간 무료. 이후 과금은 사전에 공지합니다. 결제 대금은 판매자 주소로 직접 가며 402-LAB이 보관하지 않습니다.

## MCP 서버(구매자 지갑)
- 지갑 키는 사용자의 기기에서 사용자가 지정한 프로세스가 보관합니다. 402-LAB은 키나 잔액에 접근하지 않습니다.
- 예산·건당 한도·판매자 허용 목록은 그 프로세스 안에서 강제되며, 예약된 금액은 실패해도 돌려주지 않습니다.
- 위임 상한 이하의 소액만 지갑에 넣으세요.

## 보안 범위와 한계
- 온체인 위임(Coinbase Smart Account + MandateValidator)은 별도 프로토타입이며 이 서비스에 연결돼 있지 않습니다.
- 코드는 공개돼 있고 독립 보안 감사는 받지 않았습니다.
